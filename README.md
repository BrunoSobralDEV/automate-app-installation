# automate-app-installation
## Automation Script for Installing Apps on Windows Using PowerShell

This repository contains a PowerShell script to automate the installation of applications on the Windows operating system. The goal is to streamline and speed up the setup process, enabling the installation of multiple programs quickly and without manual intervention.

### Features
- Easily install multiple applications at once.
- Speed up the setup process for new or existing machines.
- No manual intervention required—fully automated.
